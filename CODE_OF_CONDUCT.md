# Code of conduct

Manent follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the repository's issues, pull requests and reviews, and wherever someone represents the project.

In short: be respectful and kind, accept criticism of work gracefully, and focus on what is best for the people who use Manent. Harassment, insults, personal or political attacks, and publishing someone's private information are not accepted.

## Reporting

If someone's behaviour concerns you, report it through GitHub; it is the only channel.

- On a comment, an issue or a pull request, open its **…** menu and choose **Report content**. Report it to the repository's maintainers where GitHub offers that, or else to GitHub's own moderators.
- To report a person, use **Block or report** on their GitHub profile, which reaches GitHub's own moderators. Use this when the behaviour is a maintainer's: the report then does not go through the person reported.

The maintainers review every report and keep the reporter's identity private. They act as the Contributor Covenant's enforcement guidelines describe, from a private correction to a permanent ban.
