# Keyboard shortcuts

The default keys. "Ctrl" is ⌘ on a Mac unless a row says otherwise. Every command, with or without a key, is in the command palette (Ctrl+K), and **Preferences → Keyboard** (Ctrl+/) lists them all and lets you change any key that is not fixed.

## Anywhere

| Command            | Key                                                    |
| ------------------ | ------------------------------------------------------ |
| Commands (palette) | Ctrl+K                                                 |
| Go to              | Ctrl+G                                                 |
| Preferences        | Ctrl+,                                                 |
| Keyboard shortcuts | Ctrl+/                                                 |
| Next region        | F6                                                     |
| Previous region    | Shift+F6                                               |
| Undo               | Ctrl+Z (fixed)                                         |
| Redo               | ⌘⇧Z on a Mac; Ctrl+Y or Ctrl+Shift+Z elsewhere (fixed) |
| Open…              | Ctrl+O, in the desktop app only                        |

Enter, Tab and Shift+Tab move between elements as [Writing a script](writing.md#tab-and-enter) describes. That flow, the keys inside the element picker and the clipboard keys are fixed and the same for everyone.

**Zoom.** In a browser, Ctrl+=, Ctrl+- and Ctrl+0 are left to the browser's own zoom, and the page zooms from **View ▾ → Zoom**. In the desktop app they are Zoom in, Zoom out and Zoom: 100 %.

## Find and Go to

**Find** (Ctrl+F) opens the Find bar above the page, holding the selected text if there is any. It looks as you type and counts the matches ("3 of 17"). Enter goes to the next match and Shift+Enter to the previous one; Escape closes the bar. **Replace** opens a second field with **Replace** and **Replace all**; it is there only for people who can edit the script.

**Go to** (Ctrl+G) opens the command palette on places: the script's scenes ("Sc. 12 · INT. LIGHTHOUSE - NIGHT"), its pages, a character's next line, your scripts and projects, and the people in the script. Type to narrow the list, and Enter goes there.

## Commands with no key

General, End of Act, Emote, Camera, Engine Direction, Strikethrough, All-caps, the text colours and highlights, the alignments, Space before, Ruler, the other zoom commands, Where am I?, Script settings, Rename, Export…, Import…, New script, New project, Library, Sync centre, Switch person, Tour, the version history commands (Changes since, Restore, Restore this scene, Who wrote this? and the rest) and the production commands. Find them in the palette, or give them a key in Preferences → Keyboard.
