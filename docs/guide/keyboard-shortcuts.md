# Keyboard shortcuts

The default keys. "Ctrl" is ⌘ on a Mac unless a row says otherwise. Every command, with or without a key, is in the command palette (Ctrl+K), and **Preferences → Keyboard** (Ctrl+/) lists them all and lets you change any key that is not fixed.

## Anywhere

| Command            | Key                                                    |
| ------------------ | ------------------------------------------------------ |
| Commands (palette) | Ctrl+K                                                 |
| Go to              | Ctrl+G                                                 |
| Preferences        | Ctrl+,                                                 |
| Keyboard shortcuts | Ctrl+/                                                 |
| Next region        | F6                                                     |
| Previous region    | Shift+F6                                               |
| Undo               | Ctrl+Z (fixed)                                         |
| Redo               | ⌘⇧Z on a Mac; Ctrl+Y or Ctrl+Shift+Z elsewhere (fixed) |

## In a script

| Command         | Key                            |
| --------------- | ------------------------------ |
| Element picker  | Alt+Enter (⌥↵)                 |
| Scene Heading   | Ctrl+1                         |
| Action          | Ctrl+2                         |
| Character       | Ctrl+3                         |
| Parenthetical   | Ctrl+4                         |
| Dialogue        | Ctrl+5                         |
| Transition      | Ctrl+6                         |
| Shot            | Ctrl+7                         |
| Section         | Ctrl+8                         |
| New Act         | Ctrl+9                         |
| Bold            | Ctrl+B                         |
| Italic          | Ctrl+I                         |
| Underline       | Ctrl+U                         |
| Dual dialogue   | Ctrl+D                         |
| Page break      | Ctrl+Enter                     |
| Print…          | Ctrl+P                         |
| Zoom in         | Ctrl+=                         |
| Zoom out        | Ctrl+-                         |
| Zoom: Fit width | Ctrl+0                         |
| Left panel      | ⌘⌥1 on a Mac; no key elsewhere |
| Side panel      | ⌘⌥2 on a Mac; no key elsewhere |

Enter, Tab and Shift+Tab move between elements as [Writing a script](writing.md#tab-and-enter) describes. That flow, the keys inside the element picker and the clipboard keys are fixed and the same for everyone.

## Commands with no key

General, End of Act, Emote, Camera, Engine Direction, Strikethrough, All-caps, the text colours and highlights, the alignments, Space before, Ruler, the zoom presets (50 % to 300 %), Script settings, Rename, Export…, Library, Sync centre, Switch person and Tour. Find them in the palette, or give them a key in Preferences → Keyboard.

## Reserved for features not in this build

Ctrl+S (Mark a version) and Ctrl+Shift+S (Name this draft…) belong to version history, which is not in this build; they do nothing yet. Ctrl+Shift+H opens the History tab, which is empty for the same reason.
